App météo (API OpenWeatherMap)
Affiche météo d’une ville ou géolocalisation avec température, vent, humidité et icône. Fond dynamique selon météo. Multi-villes possible. Travail sur fetch(), DOM et affichage dynamique.

Technologies utilisées:
-HTML5
-CSS3
-JavaScript (ES6+)
-WeatherAPI
-Git / GitHub

Fonctionnalités principales:
✔ Rechercher la météo via le nom d’une ville
✔ Météo via géolocalisation automatique
✔ Affichage des données principales :
  -température
  -vent (km/h)
  -humidité
  -condition météo
  -icône météo
✔ Changement automatique du fond selon :la météo (ex: sunny, cloudy, rain, etc.) l’heure (jour / nuit)
✔ Capacité d’ajouter plusieurs villes
✔ Interface responsive
✔ Gestion des erreurs (ville inconnue, absence GPS, API non disponible)

Nouveautés explorées :
-Utiliser fetch() avec une API externe en JSON
-Manipuler et mettre à jour dynamiquement le DOM
-Gérer les promesses, les erreurs et les réponses API
-Convertir et comparer des heures (lever / coucher du soleil)
-Changer dynamiquement :
  .les images
  .les backgrounds
  .les icônes
-Manipulation des éléments CSS via JavaScript
-Compréhension du fonctionnement d’un système météo : condition, vent, humidité…

Difficultés rencontrées :
-clé API
-Erreurs liées au DOM
-Affichage dynamique des images selon la météo
-Parsing et comparaison des heures (sunrise / sunset)

Solutions apportées :
-Tests console et logs pour détecter les erreurs rapidement
-Lecture de la documentation WeatherAPI
